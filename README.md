# Эмулятор оболочки (вариант 5)

Практическая работа по дисциплине «Конфигурационное управление».
Текущий этап: **2. Конфигурация** (функциональность этапа 1 сохранена).

## 1. Общее описание

Консольный (CLI) эмулятор оболочки UNIX-подобной ОС, написанный на Python.
Работает в цикле «прочитать строку, выполнить, вывести результат» (REPL).

Реализовано:

- приглашение к вводу вида `(имя_VFS) username@hostname:~$`; имя пользователя
  и хоста берутся из реальной ОС, имя VFS из параметра `--vfs`;
- парсер, который раскрывает переменные окружения реальной ОС (`$HOME`,
  `${HOME}`) и делит строку на команду и аргументы по пробелам;
- сообщения об ошибках (неизвестная команда, неверные аргументы);
- команды-заглушки `ls`, `cd` и команда `exit`;
- параметры командной строки: путь к VFS и путь к стартовому скрипту;
- отладочный вывод всех параметров при запуске;
- выполнение стартового скрипта как диалога: виден и ввод, и вывод.

Виртуальная файловая система и остальные команды появятся на следующих
этапах: на этапе 2 путь к VFS только запоминается и выводится, файл
не открывается.

## 2. Описание функций и настроек

### Параметры командной строки

| Параметр          | Описание                                              |
|-------------------|-------------------------------------------------------|
| `--vfs ПУТЬ`      | Путь к физическому расположению VFS                   |
| `--script ПУТЬ`   | Путь к стартовому скрипту                             |
| `-h`, `--help`    | Справка по параметрам                                 |

Оба параметра необязательны. Сокращения (`--vf`) не принимаются. Неизвестный
параметр или параметр без значения приводит к подсказке по использованию
и завершению с кодом 2.

Имя VFS в приглашении это последний элемент пути из `--vfs`
(`data/disk.xml` даёт `disk.xml`). Без `--vfs` используется имя `vfs`.

### Отладочный вывод

При запуске после приветствия печатаются все параметры:

```
[отладка] Параметры запуска:
[отладка]   --vfs:    data/disk.xml
[отладка]   --script: startup/minimal.emu
[отладка]   имя VFS в приглашении: disk.xml
```

Незаданный параметр показывается как `(не задан)`.

### Стартовый скрипт

Текстовый файл в кодировке UTF-8 (BOM допускается), по одной команде эмулятора
в строке. Правила:

- строки выполняются последовательно, на экране видно приглашение, введённая
  строка и вывод, как при ручном вводе;
- пустые строки и строки, начинающиеся с `#`, пропускаются без вывода;
- ошибочная строка (неизвестная команда, неверные аргументы) пропускается,
  печатается сообщение `Ошибка (строка N): ...` с номером строки в файле,
  выполнение продолжается;
- команда `exit` в скрипте завершает работу эмулятора, остальные строки
  не выполняются;
- если скрипт закончился без `exit`, запускается интерактивный режим;
- если файл не найден или не читается, печатается сообщение в stderr,
  эмулятор завершается с кодом 1.

### Коды возврата

| Код | Значение                                            |
|-----|-----------------------------------------------------|
| 0   | Нормальное завершение                               |
| 1   | Не удалось прочитать стартовый скрипт               |
| 2   | Неверные параметры командной строки                 |

### Команды

| Команда        | Описание                                                          |
|----------------|-------------------------------------------------------------------|
| `ls [арг...]`  | Заглушка: печатает своё имя и список аргументов                   |
| `cd [арг]`     | Заглушка: печатает своё имя и аргументы. Больше одного аргумента: ошибка |
| `exit`         | Завершает работу эмулятора. С аргументами: ошибка                 |

В интерактивном режиме `Ctrl+D` и `Ctrl+C` тоже завершают работу.

### Ошибки

| Ситуация                         | Сообщение                                       |
|----------------------------------|-------------------------------------------------|
| Неизвестная команда              | `Ошибка: неизвестная команда 'foo'`             |
| `cd` с двумя и более аргументами | `Ошибка: cd: слишком много аргументов`          |
| `exit` с аргументами             | `Ошибка: exit: команда не принимает аргументов` |

В скрипте к тексту добавляется номер строки: `Ошибка (строка 3): ...`.

### Раскрытие переменных окружения

Переменные раскрываются до разбиения на слова, поэтому значение с пробелами
превращается в несколько аргументов. Неопределённая переменная остаётся
в строке без изменений (`$NOPE` остаётся `$NOPE`). Пустая переменная
в начале строки даёт пустую команду, которая игнорируется.

## 3. Сборка и запуск тестов

Нужен Python 3.9 или новее. Внешних зависимостей нет, сборка не требуется.

```
make run                                  # интерактивный режим
make run ARGS="--vfs data/disk.xml --script startup/minimal.emu"
make test                                 # тесты (unittest)
make lint                                 # стиль, нужен flake8
```

Без `make`:

```
python3 src/terminalus.py --vfs data/disk.xml --script startup/minimal.emu
python3 -m unittest discover -s tests -t . -v
```

### Скрипты реальной ОС

Каждый скрипт вызывает эмулятор для проверки всех параметров командной строки:
без параметров, только `--vfs`, только `--script`, оба сразу и `--help`.
Запускать можно из любой папки. Для Linux/macOS это `.sh`, для Windows `.bat`
(в нём включается кодировка UTF-8). Переменная `PYTHON` позволяет выбрать
интерпретатор (по умолчанию `python3`, в Windows `python`).

| Скрипты (`.sh` и `.bat`)   | Стартовый скрипт эмулятора | Что проверяют                     |
|----------------------------|----------------------------|-----------------------------------|
| `scripts/run_minimal`      | `startup/minimal.emu`      | все параметры                     |
| `scripts/run_with_errors`  | `startup/with_errors.emu`  | ошибочные строки, коды 1 и 2      |
| `scripts/run_all_commands` | `startup/all_commands.emu` | все команды, переменные окружения |

```
sh scripts/run_minimal.sh
scripts\run_minimal.bat
```

## 4. Примеры использования

Пример запуска со скриптом `startup/all_commands.emu`
(`student@pc` это пользователь и хост реальной ОС, `EMU_DEMO_DIR=/opt/demo`):

```
Эмулятор запущен под учётной записью student@pc
Доступные команды: ls, cd, exit

[отладка] Параметры запуска:
[отладка]   --vfs:    data/disk.xml
[отладка]   --script: startup/all_commands.emu
[отладка]   имя VFS в приглашении: disk.xml

(disk.xml) student@pc:~$ ls
[заглушка] команда: ls
[заглушка] аргументы: []
(disk.xml) student@pc:~$ ls -l
[заглушка] команда: ls
[заглушка] аргументы: ['-l']
(disk.xml) student@pc:~$ ls -a /tmp
[заглушка] команда: ls
[заглушка] аргументы: ['-a', '/tmp']
(disk.xml) student@pc:~$ cd /home
[заглушка] команда: cd
[заглушка] аргументы: ['/home']
(disk.xml) student@pc:~$ cd $EMU_DEMO_DIR
[заглушка] команда: cd
[заглушка] аргументы: ['/opt/demo']
(disk.xml) student@pc:~$ cd ${EMU_DEMO_DIR}/sub
[заглушка] команда: cd
[заглушка] аргументы: ['/opt/demo/sub']
(disk.xml) student@pc:~$ foo
Ошибка (строка 15): неизвестная команда 'foo'
(disk.xml) student@pc:~$ cd one two
Ошибка (строка 16): cd: слишком много аргументов
(disk.xml) student@pc:~$ exit now
Ошибка (строка 17): exit: команда не принимает аргументов
(disk.xml) student@pc:~$ exit
Завершение работы эмулятора.
```

Стартовый скрипт не найден:

```
Эмулятор запущен под учётной записью student@pc
Доступные команды: ls, cd, exit

[отладка] Параметры запуска:
[отладка]   --vfs:    (не задан)
[отладка]   --script: startup/not_exists.emu
[отладка]   имя VFS в приглашении: vfs

Ошибка: не удалось прочитать скрипт 'startup/not_exists.emu': Нет такого файла или каталога
```

```
scripts/*.sh, scripts/*.bat скрипты реальной ОС

README.md
```
